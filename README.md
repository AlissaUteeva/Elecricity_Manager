# Elecricity_Manager/Анализатор потребления электроэнергии
Ссылка на скачивание программы https://github.com/AlissaUteeva/Elecricity_Manager/releases/tag/v6

## Задача
Проект разработан для автоматизации учёта расходов электроэнергии бытовыми приборами за неделю, выявления наиболее энергозатратных устройств и формирования отчётов с рекомендациями.

## Стек
Python 3.11 / CSV
библиотеки: Matplotlib, OS, Sys
формат данных: CSV, Markdown, PNG

## Как запустить
### Вариант 1: быстрый запуск
1. Перейдите в раздел **Releases** справа на панели GitHub или по ссылке выше и скачайте архив `ElectricityManager.zip`
2. Распакуйте архив в любую удобную папку на компьютере
3. Запустите файл `ElectricityManager.exe`
4. Введите тестовые тарифы в консоль, результаты анализа сохранятся в этой же папке

### Вариант 2: запуск через консоль
1. Зайдите в корневую папку проекта
cd Electricity_Manager
2. Установите графическую библиотеку (не нужно если уже устанавливали)
py -m pip install matplotlib
py -m pip install pandas
4. Запустите приложение напрямую из исходников
py src/main.py

### Как сохранить собственные данные
1. **Откройте файл с данными:** Зайдите в папку с программой, перейдите в `data/` и откройте файл `primer.csv` через обычный **Блокнот** или текстовый редактор
2. **Внесите изменения, строго соблюдая формат:**
   * Каждая строка должна содержать три значения через запятую: `дата,прибор,квт/ч`
   * **Важно:** Дробная часть киловатт должна отделяться **точкой**, а не запятой, например: `1.5`, а не `1,5`
   * В файле должно быть как минимум 5 разных названий приборов, чтобы программа смогла корректно построить график
3. **Правильное сохранение:** 
   * Нажмите *Файл -> Сохранить* (или Ctrl + S)
   * **Критически важно:** Если Блокнот предложит выбрать кодировку, убедитесь, что выбрана UTF-8
4. **Запуск:** Запустите `ElectricityManager.exe` заново. Программа автоматически подставит новые данные и подготовит отчет

## Тестирование
1. **Успешный сценарий:** Обработка файла `primer.csv`. Математический расчёт стоимости и экономии полностью совпадает со счётом на калькуляторе
2. **Защита от ошибок ввода:** Модуль `main.py` содержит обработку ввода данных запрашивая повторный ввод.
Описание тестов в docs/Тесты ElectricityManager.docx

## Структура проекта
* `src/main.py` — главный файл и точка входа
* `src/core.py` — логика: чтение данных, группировка и расчёты
* `src/ui.py` — построение графиков (matplotlib) и сохранение PNG
* `src/test_core.py` — автоматические тесты (проверка расчетов)
* `data/primer.csv` — таблица с расходами энергии (исходные данные)
* `data/primer.txt` — блокнот для записи расходов энергии (текстовое описание)
* `docs/Тесты ElectricityManager.docx` — файл с описанием ручных тестов
* `images/` — папка с графиками и скриншотами для отчёта:
    * `border_cases.png` — скриншот проверки граничных случаев
    * `consumption_chart.png` — график потребления (топ-5)
    * `report.png` — скриншот сгенерированного отчета
